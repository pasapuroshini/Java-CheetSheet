### Key Points on Abstract Classes:

1.  **Definition**:
    
    *   An **abstract class** is a class that may contain **zero or more abstract methods** (methods without implementation).
        
2.  **Components of an Abstract Class**:
    
    *   **Abstract methods** (declared using the abstract keyword, no implementation).
        
    *   **Instance variables**.
        
    *   **Concrete methods** (methods with implementation).
        
3.  **Keyword Usage**:
    
    *   Both the abstract class and its abstract methods must be declared with the abstract keyword.
        
4.  **Implementation in Subclasses**:
    
    *   All abstract methods of an abstract class must be implemented in its subclasses.
        
    *   If a subclass does not implement all abstract methods, it must also be declared **abstract**.
        
5.  **Restrictions on Instantiation**:
    
    *   You cannot create an object of an abstract class.
        
    *   However, a **reference of an abstract class type** can be used to refer to objects of its subclasses.
        
6.  **Subclass Rules**:
    
    *   If a subclass does not implement all abstract methods, it must:
        
        *   Be declared as **abstract**.
            
        *   Require further subclassing to implement the remaining abstract methods.
            
7.  **Object Class Reference**:
    
    *   A reference of the Object class **cannot directly access** methods unique to subclasses.
        
8.  **Inheritance from Concrete Classes**:
    
    *   An abstract class can be derived from a **concrete superclass**.
        
9.  **Abstract and Final Conflict**:
    
    *   A class **cannot** be both abstract and final because:
        
        *   The final keyword prevents inheritance.
            
        *   The abstract keyword requires inheritance for implementation.
            
        *   These two keywords are contradictory and cannot be used together.
            
10.  **Key Question**:
    
    Can you declare a class as both abstract and final?
        
        No, it is not allowed due to the conflicting purposes of the two keywords.
